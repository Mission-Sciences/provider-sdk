# General Wisdom SDK — Vanilla JS Example

Integrates the `@mission_sciences/provider-sdk` into a plain HTML/JavaScript page via CDN.

## Prerequisites

1. **Create an application:** https://platform.generalwisdom.com/developer/applications
2. **Generate your API key:** https://platform.generalwisdom.com/developer/api-key

## Install

```bash
npm install @mission_sciences/provider-sdk
```

## Setup

Replace `YOUR_APP_ID` and `YOUR_API_KEY` in `index.html` with the values from your General Wisdom developer account.

## Run

Open `index.html` in a browser, or serve it with any static file server:

```bash
npx serve .
```

Opens at http://localhost:3101
