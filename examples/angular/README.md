# General Wisdom SDK — Angular Example

Integrates the `@mission_sciences/provider-sdk` into an Angular application.

## Prerequisites

1. **Create an application:** https://platform.generalwisdom.com/developer/applications
2. **Generate your API key:** https://platform.generalwisdom.com/developer/api-key

## Install

```bash
npm install @mission_sciences/provider-sdk
```

## Setup

Replace `YOUR_APP_ID` and `YOUR_API_KEY` in `src/app/app.component.ts` with the values from your General Wisdom developer account.

## Run

```bash
npm install
npm run dev
```

Opens at http://localhost:3105
